# Security Policy

This is a recruitment Proof of Concept, not a production service — there is no support
window or version matrix to speak of. If you find a security issue, please report it
privately rather than opening a public GitHub issue.

## Reporting a Vulnerability

Please use GitHub's [private vulnerability reporting](https://github.com/michalper/wskz/security/advisories/new)
for this repository. You should get an initial response within a few days.
